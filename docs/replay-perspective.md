# 赛事回放：跟随行动玩家

2026-09-09，已实现并接入本地 DSH 赛事回放。

## 使用方式

在回放顶部的“观察模式”中选择“跟随行动玩家”。当前行动玩家自动成为牌桌下方的观察对象，显示该玩家手牌；摸入的牌沿用原牌桌的独立摸牌位置。

选择“固定玩家”则恢复之前手动选择的选手。旧会话默认维持固定玩家模式。模式、固定选手和回放位置随当前会话保存，刷新或重启后保留。

## 切换规则

| 当前回放步骤 | 显示谁的手牌 |
| --- | --- |
| 发牌、换三张、定缺等共同阶段 | 庄家 |
| 摸牌 | 摸牌者，摸入牌单独显示 |
| 弃牌 | 弃牌者，展示弃牌后的手牌；不提前切到下一家 |
| 碰、明杠、暗杠、补杠 | 执行动作者 |
| 荣和、自摸 | 本次胡牌者；下一动作出现时继续跟随 |
| 终局结算 | 最后一位行动者 |
| 倒退、任意跳转 | 目标步骤的行动者 |

自动播放、顶部前后步与牌桌内前后步使用相同规则。跟随模式下选手下拉框显示当前观察者，并暂停手动选人；切回固定模式后可继续选择。

例如当前 S6 牌谱：第 9 步春光摸五条，显示春光手牌及独立五条；第 10 步春光打二筒，仍看春光；第 11 步周猩猩碰二筒，切到周猩猩。

## 数据与问答边界

行动者根据源牌谱事件的稳定 ID 获取，旧快照可用事件序号匹配。不使用弃牌后已经轮转的 `turn`，也不根据步骤标题猜玩家。缺少行动记录的旧案例保持可用的固定模式，跟随选项不可选。

视角切换不重写源牌谱、不生成新牌谱版本，也不修改摸打、手牌、副露、积分或余牌数据。真实牌桌沿用同一个 iframe，保持 1280×720 画布按 16:9 完整缩放。

已有问答继续绑定原先的步骤、座位和版本。点击“提问这一步”时，新问答绑定眼前实际观察的玩家；之后自动跟随不会改变已建立问答的局面。

纠错草稿预览同样跟随所选草稿事件，状态文字显示预览玩家。取消回到正式回放；保存后继续跟随保存位置。程序验收证明视角符合当前牌谱，不等于原视频与牌谱已全部核实。

## 实现与回退

`lib/source-cases.js` 解析行动者及观察模式；`lib/game-controller.js` 统一导航、问答和纠错预览；`lib/session-game-store.js` 保存观察偏好；`lib/http-api.js` 接受观察模式参数；`client.js` 提供切换入口。

会话元数据新增可选 `viewMode: fixed | follow`、`fixedSeat`。`seat` 仍代表当前画面的实际观察者，`questionSeat` 仍固定绑定问答。

使用上可随时切回“固定玩家”。代码回退应只撤回上述功能增量及对应测试、文档，保留此前纠错功能和用户其他修改；无需恢复牌谱文件。
