## 已实现和验证

- `service/` 新增独立 Cloudflare Worker + SQLite Durable Object，每桌保存自己的状态。提取 14 个规则/推荐相关代码文件，记录来源版本、工作区源哈希、提取时哈希与最终版本哈希，保留上游代码许可。
- 血战引擎、合法动作、原 Top1 超时回退、引擎秘密状态恢复已脱离 MJAI。没有迁入账号、支付、PostgreSQL、其他 AI 调用或私有接口。
- 默认决策窗口 38 秒，可设 10–120 秒；持久化绝对截止时间。坏动作不落库，成功确认可重发去重。Cloudflare Alarm 处理到期和动画/结算等待，不依赖常驻定时器。
- owner 管理凭证与各席/查看凭证分离。租户及同租户不同 owner 隔离；AI 只得到本人私有手牌与公开动作，墙中未来牌对所有实时观察者隐藏。
- Harness 插件增加可配置 `service` 后端与逐桌 WebSocket 地址；模型密钥、provider 配置和会话仍留在本地。旧运行配置、启动脚本、牌桌前端与 Harness 核心均未在本阶段更换。
- 新增 4 项插件侧测试，根目录共 **100 项通过**；独立服务 **12 项通过**。其中 5 项测试覆盖 0/1/2/3/4 真人阵容完整血战，每个动作后重载快照；这些属于规则/恢复测试，不能代替真人 UI 和真实模型验收。
- 真实本地 workerd 联调覆盖四席 Harness 传输握手、动作拒绝后继续操作、跨租户/跨桌主拒绝、查看凭证不可出牌、SQLite 进程重启恢复、同一决策与手牌继续、原截止时刻触发真实 Alarm。
- TypeScript 检查、来源校验和 Wrangler 部署包试构建通过；没有登录 Cloudflare 或创建任何远端资源，没有调用模型 API。
