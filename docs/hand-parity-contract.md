# `/hand/` 原样复用契约

## 目标

`dsh-mahjong` 中的牌局不是参考 `/hand/` 重新实现，而是复用可追溯版本的真实 `/hand/`。Harness 只负责承载、会话和外围信息。

## 独立交付与复用来源

2026-09-05 已确认：最终只需 DeepSeek Harness + dsh-mahjong，不依赖 mjai 仓库或服务，详见 [独立运行交付需求](standalone-delivery.md)。

- `/hand/` 来源于 MJAI，不意味着最终用户需要安装 MJAI。完成来源与许可核查后，将真实实现、递归依赖和获准资源纳入 dsh-mahjong 自身交付，在本仓库构建、发布和服务页面。
- 保留下面的源版本、哈希、许可与视觉/交互验证记录；历史来源信息可以指向 MJAI，但正常构建、安装、启动和验收不要求访问 mjai 私有仓库。
- 不允许以引用用户桌面的 mjai 路径、访问其私有静态资源或代理其牌桌服务来伪装独立运行，也不允许以截图、仿制 UI 或重画牌桌替代真实 `/hand/`。
- 若资源许可与独立分发要求冲突，先说明具体缺口并取得用户决定，不擅自复制或替换；本条为最初文档阶段的边界；2026-09-07 用户明确回复“已有授权，请你继续”，现按该授权迁移原牌桌与素材，仍保留上游各自条款。

## 必须一致

- 1280 x 720 设计坐标系。
- 运行时等比 `contain` 缩放并居中。
- 多余区域只做背景补齐，不承载交互。
- 牌面、牌背、桌布、座位、手牌、副露、弃牌、中心区和 HUD。
- 发牌、摸牌、出牌、碰、杠、胡、过、换三张、定缺、结算和牌谱交互。
- 动画时序、音效触发、触控与鼠标行为。
- 加载、断线、重连、等待、错误和结束状态。

## Harness 可以增加

- 牌桌外部的会话列表与对话区。
- 座位与 Harness agent 会话的映射。
- 模型名称、思考状态、倒计时和动作流水，但不得覆盖或改变牌桌原有交互。
- 在一栏、两栏、三栏之间切换时的容器尺寸与挂载逻辑。

## 禁止

- 用截图、生成图或仿制 DOM 代替真实牌桌。
- 为适配侧栏而修改牌桌内部比例或重新排版。
- 未经确认替换牌面、桌布、字体、音效或交互。
- 在没有来源版本和许可记录时复制素材。

## 版本与验证

导入前必须生成 `hand-parity-manifest`，记录：

- MJLab Git commit。
- 入口文件及递归依赖文件。
- 资源文件及哈希。
- 构建工具和锁文件版本。
- 固定场景截图与关键交互清单。

每次同步 `/hand/` 后至少验证：

1. 1280 x 720 基准截图无非预期视觉差异。
2. 1920 x 1080 两栏容器中保持完整画布且不裁切。
3. 窄容器中仍按 `contain` 缩放，无内部重排。
4. 一次完整血战流程的关键动作可操作。
5. Console 无新增错误，WebSocket 重连行为保持一致。
6. 最终发布前，在无 mjai 源码、进程与资源服务的干净环境中，由 dsh-mahjong 自身提供真实牌桌，重复以上视觉与交互验证；禁止回源 mjai。

## 标准国标适配（2026-09-07）

按已确认的标准国标需求，前后端计番统一为相同的 81 番种实现，原 HUD 的规则文字同步更新并去掉原型增补番种说明。两处规则适配单独登记在 manifest 的 `rulesAdaptations`，不冒充逐字未修改的来源文件；477 个素材仍保持原字节，牌桌布局、绘制、动画与操作不变。
