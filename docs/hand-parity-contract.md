# `/hand/` 原样复用契约

## 目标

`dsh-mahjong` 中的牌局不是参考 `/hand/` 重新实现，而是复用可追溯版本的真实 `/hand/`。Harness 只负责承载、会话和外围信息。

## 必须一致

- 1280 x 720 设计坐标系。
- 运行时等比 `contain` 缩放并居中。
- 多余区域只做背景补齐，不承载交互。
- 牌面、牌背、桌布、座位、手牌、副露、弃牌、中心区和 HUD。
- 发牌、摸牌、出牌、碰、杠、胡、过、换三张、定缺、结算和牌谱交互。
- 动画时序、音效触发、触控与鼠标行为。
- 加载、断线、重连、等待、错误和结束状态。

## Harness 可以增加

- 牌桌外部的会话列表与对话区。
- 座位与 Harness agent 会话的映射。
- 模型名称、思考状态、倒计时和动作流水，但不得覆盖或改变牌桌原有交互。
- 在一栏、两栏、三栏之间切换时的容器尺寸与挂载逻辑。

## 禁止

- 用截图、生成图或仿制 DOM 代替真实牌桌。
- 为适配侧栏而修改牌桌内部比例或重新排版。
- 未经确认替换牌面、桌布、字体、音效或交互。
- 在没有来源版本和许可记录时复制素材。

## 版本与验证

导入前必须生成 `hand-parity-manifest`，记录：

- MJLab Git commit。
- 入口文件及递归依赖文件。
- 资源文件及哈希。
- 构建工具和锁文件版本。
- 固定场景截图与关键交互清单。

每次同步 `/hand/` 后至少验证：

1. 1280 x 720 基准截图无非预期视觉差异。
2. 1920 x 1080 两栏容器中保持完整画布且不裁切。
3. 窄容器中仍按 `contain` 缩放，无内部重排。
4. 一次完整血战流程的关键动作可操作。
5. Console 无新增错误，WebSocket 重连行为保持一致。
