## 开发与本地验收

- 原生牌桌随包独立交付，558 个来源文件、477 项图片/字体/声音的字节一致性通过检查。10 项传输与标准国标适配均有清单；1280×720 等比居中，原动画、音效和牌面保留。
- 标准国标采用 MCR 81 番种、8 番门槛（花牌不计门槛），删除原型增补计番，浏览器与服务端计算文件一致。血战保持原规则。合法动作、计分、超时和恢复由服务器决定。
- 根插件 97 项自动化测试通过；服务规则与真实 workerd/SQLite/WebSocket 集成 158 项通过。覆盖 0–4 真人、凭据隔离、错误/重复/过期动作、换三张与定缺、国标吃碰杠补花、托管、重启、历史和用户管理。
- 独立 npm 安装包从新目录安装和构建成功，以 3083/8788 自定义端口启动官方 Harness 与独立牌桌；未读取或启动原 MJAI 项目。模型配置和私有会话留在本地，Harness 核心未修改。
- 在真实浏览器完成牌谱导出→导入→逐步播放，导入牌谱禁止继续练习；无效 JSON 给出可读错误。分享无需登录可逐步播放，撤销后链接失效。
- 历史步骤问答使用官方 Harness 原生输入框和独立可见会话；步骤切换及问答伸缩保持同一 iframe。模型回答只依据固定步骤；存档后恢复的不可变上下文有测试。
- 四个教练关卡均通过真实牌桌操作验证：换三张、定缺、清缺弃牌、带幺九。实际超时显示重练反馈；重启后已通过和练习次数保留。
- 管理界面真实创建验收用户，将配额改为 2 桌/12 份记录，撤销后状态立即更新。邀请一次领取、撤销后旧凭证失效、跨用户隔离通过集成测试。
